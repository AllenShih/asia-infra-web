# AWS 啟用泰國雲端區域，設置三個可用區

AWS 表示，新區域由三個可用區組成，並獲得公司在泰國規劃逾 50 億美元投資的支持。

Amazon Web Services 於 2025 年 1 月 7 日啟用 AWS Asia Pacific (Thailand) Region，讓客戶能在泰國境內執行工作負載及儲存資料。

## 事件內容

此次啟用新增一個由三個可用區組成的泰國 AWS 區域。AWS 表示，這些可用區在實體上彼此分離，但透過備援、低延遲網路互相連接，以支援具韌性的雲端部署。

## 主要資料

- **專案：** AWS Asia Pacific (Thailand) Region
- **地點：** 泰國
- **產業：** 資料中心
- **配置：** 三個可用區
- **長期投資計畫：** 超過 50 億美元
- **開發商與營運商：** Amazon Web Services
- **事件類別：** COD

## 重要性

新區域擴大泰國境內的超大規模雲端容量，並讓當地組織在資料落地與低延遲服務方面有更多選擇。三個可用區的架構也為跨獨立設施部署工作負載、提升系統韌性提供基礎。

## 專案與公司背景

AWS 將這筆投資描述為涵蓋區域建設與營運的長期承諾。該金額並非單一資料中心或單一可用區已揭露的 CAPEX。
